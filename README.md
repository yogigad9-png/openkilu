# 💫 About Me:
I'm an AI enthusiast and developer working on **KILU (MARK LVI)** — a personal AI desktop assistant designed to bring intelligent automation, local AI, persistent memory, and multi-agent workflows into one unified system.<br><br>## 🚀 Currently Working On<br><br>- 🤖 **KILU / MARK LVI:** Developing a PyQt6-based desktop AI assistant with a futuristic HUD interface, floating panels, and an interactive workspace.<br>- 🧠 **Long-Term Memory:** Building persistent memory that helps KILU retain useful information across conversations and application restarts.<br>- 🛠️ **Multi-Agent System:** Connecting specialized agents such as DevAgent and Video Agent so KILU can delegate tasks, track execution, and report actual results.<br>- 🎬 **AI Video Agent:** Developing a video workflow for media analysis, scene detection, transcription, subtitle generation, edit decision lists, and CapCut draft creation.<br>- 🎨 **AI Image Generation:** Exploring local image models and supported free AI providers to generate and edit images without making paid API access mandatory.<br>- 💻 **Developer Automation:** Working on code execution, project analysis, tool integration, task orchestration, and automated testing.<br>- 📱 **Remote Access:** Exploring secure ways to interact with KILU through a phone or browser on the local network.<br>- 🔌 **Free AI Integrations:** Exploring Ollama, free-tier model providers, and supported authentication methods to reduce dependence on paid APIs.<br><br>## 🧰 Technologies & Tools<br><br>- **Languages:** Python, JavaScript, HTML, CSS<br>- **Desktop Development:** PyQt6<br>- **AI & Models:** Ollama, Gemini, OpenAI-compatible providers, local AI models<br>- **Backend & APIs:** FastAPI, REST APIs<br>- **Data & Memory:** SQLite, JSON, persistent knowledge systems<br>- **Development Tools:** Git, GitHub, VS Code, Windows, PowerShell<br>- **Media Processing:** FFmpeg, Whisper-based transcription workflows, CapCut draft integration<br><br>## 🎯 My Vision<br><br>My goal is to evolve KILU into a capable personal AI operating environment that can understand natural-language instructions, select the right tools, delegate complex tasks to specialized agents, remember useful context, and execute real workflows with transparent progress and verifiable results.<br><br>I want KILU to prioritize:<br><br>- 🔒 Privacy-conscious, local-first workflows<br>- 💸 Free and open-source tools wherever practical<br>- 🧩 Modular architecture and reusable agents<br>- ⚙️ Real functionality instead of fake buttons or simulated results<br>- 🧪 Evidence-based testing and reliable error handling<br>- 🧠 Persistent memory and intelligent task routing<br>- 🎨 A modern, futuristic desktop experience<br><br>## 🌱 Currently Learning<br><br>AI agent architecture, local LLM integration, desktop application engineering, API authentication, automation, memory systems, multimedia processing, and software testing.<br><br>## 🤝 Looking to Collaborate
