# 💫 About Me:
Mark LV gave the assistant a screen. **Mark LVI lets you choose what runs it.**<br><br>Until now this was a Gemini assistant, and only that. If you had no quota left, no<br>connection, or a rule that says your microphone does not leave the building, you<br>had no assistant. Mark LVI adds a second way to hold the conversation — speech<br>recognition, a language model and a voice, assembled from parts you pick in<br>⚙ → **ENGINE & PROVIDERS** — and a way to point the assistant's own background<br>requests at a different model without touching the voice at all.<br><br>The local model can be on your machine (Ollama, LM Studio, llama.cpp, vLLM) or<br>somebody else's API (OpenAI, Groq, DeepSeek, Mistral, xAI, OpenRouter, Together).<br>Both are the same setting, because all of them speak the same protocol.<br><br>**None of it costs anything if you do not use it.** On a default install the<br>`providers/` folder is never imported — not at startup, not on a tool call, not<br>when the settings drawer opens. Measured: the decision takes **0.16 ms** and<br>loads nothing. The folder can be deleted, and deleting it changes nothing.<br><br>Everything the assistant already does carries over untouched. A local engine<br>inherits the avatar, the lip-sync, the self-echo guard, push-to-talk, the wake<br>word, memory, undo, the confirmation gate and every action and plugin — because<br>it enters through the same door the Live session always did.<br><br>Mark LVI also changes what the assistant is allowed to CLAIM. Every tool that<br>drives an application now answers with what it observed rather than with what it<br>attempted: `done` means it was checked, `unverified` means the request went out<br>and could not be confirmed — and the assistant says exactly that instead of<br>rounding it off to "done". Opening an app watches the process table for it.<br>Closing one asks the application politely, then checks whether it went.<br><br>It's not just an assistant — it's an extension of your digital life.
